# Midnight Toy Workshop

A cosy VR repair game made by **Titiksha Raj Pandey**.

It's 11 pm in an old toymaker's workshop and tonight's toys are broken. You fix them one by one with your hands, and every repair moves the cuckoo clock closer to midnight. At midnight every toy you fixed comes alive.

Built with Unity 6 (URP, XR Interaction Toolkit, OpenXR) for a Meta Quest over Quest Link. All the art comes from Blender scripts.

## The night

| # | Task | What you do |
|---|------|-------------|
| 1 | Fix the steam train | Fit 5 parts from the tray (front and back wheels, chimney, cowcatcher, key), then wind the key with 3 hand circles. The train hops onto the toy-town track and drives off. |
| 2 | Mend the music box | Take the crank from the workbench to the music box on the mantel, fit it, and wind it. The lid opens, the ballerina spins and the tune plays. |
| 3 | Fix the jack-in-the-box | Find his three missing parts around the workshop (jester hat on the armchair, crank on the toy-town table, lid on the fireplace hearth) and fit them, then wind him. The first wind squashes the jester back into his box, and on the third he pops out. |
| 4 | Catch the clockwork mouse | It scurries round the floor (NavMesh) and runs away from you. Grab it when it stops to sniff. |
| 5 | Greet the tin soldier | He marches a patrol. Look at him and wave (swipe) and he salutes. Push towards him and he falls over, then gets back up. |
| ★ | Midnight | The cuckoo clock strikes, confetti falls, every toy performs, then the end screen shows your time and hints used. |

## Controls

| Action | Quest controllers | Simulator (keyboard and mouse) |
|---|---|---|
| Grab a part | Grip | G |
| Press buttons, use menus | Trigger (point the ray) | T or mouse click |
| Move | Left thumbstick | WASD |
| Turn or teleport | Right thumbstick | mouse |
| Pause | Left Menu button | Esc or P |
| Wind up a toy | Circle your hand 3 times | — |
| Wave | Swipe left or right | — |
| Push | Push your hand forward | — |

The toymaker's hint panel appears when you walk up to him. It has three questions: "What do I do next?", "How does it work?" and "Tell me about this toy".

## Running it

1. Open the project in **Unity 6000.3**, then open `Assets/Scenes/Workshop.unity`.
2. Desk testing: just press Play. The XR Interaction Simulator stands in for the headset.
3. Headset: install Meta Quest Link, set it as the active OpenXR runtime (Link app → Settings → General), connect the Quest, start Link, then press Play. The simulator switches itself off when a headset is found.
4. Optional AI hints: install [Ollama](https://ollama.com), run `ollama pull llama3.2`, and keep Ollama running. Without it, the toymaker gives his built-in hints.

The scene rebuilds itself from the Blender art whenever the layout or the game setup changes. **Workshop → Build Workshop From Blender Art** forces a rebuild.

## What's new and interesting about it

- **Gestures bring toys to life.** A small neural network (trained by `Tools/train_gesture_model.py`, exported to ONNX, run with Unity Inference Engine) recognises hand circles, swipes and pushes from the controller's movement. Winding a toy means actually winding it.
- **An offline AI character.** The toymaker answers with a local LLM (llama3.2 through Ollama). Each question carries the game state (what's fixed, what's next), so the hints fit the moment. It runs on the CPU, so the GPU stays free for smooth VR, and nothing leaves the computer.
- **Everything is made by code.** Every model, texture, animation, sound and UI image is generated by scripts: Blender for the art, Python for textures, UI and sound. Nothing was downloaded.

## Benefit to society

- **Repair, don't replace:** the whole game is about fixing things instead of throwing them away.
- **Hands-on STEM learning:** "How does it work?" explains real mechanisms (springs, gears, pinned drums, cams), and fitting parts teaches cause and effect in 3D.
- **Privacy-friendly:** all the AI runs locally and no personal data is collected or sent anywhere, which makes it safe for children and schools.
- **Calm and non-violent:** no timer and no way to fail, so it suits all ages and people new to VR.

## Project layout

| Folder | What's in it |
|---|---|
| `Assets/Scripts` | Gameplay. `Game/` holds the night's flow, tasks, chalkboard, guide star and sounds; `Toys/` one script per toy task; `AI/` the Ollama client and the toymaker; `UI/` the menus. |
| `Assets/Scripts/Editor` | Builds the scene: lays out the Blender art (`WorkshopV2Layout`), sets up the game (`WorkshopGameSetup`), plus import rules and materials. |
| `Blender/scripts` | Python that builds every asset in Blender 5.2: `phase1_assets` (room and furniture), `phase2_toys` (the six toys), `phase3_assets` (chalkboard, controller art), `phase2_assembly` (the whole workshop and the layout file). |
| `Blender/Phase1..3` | The `.blend` files (modifiers and animations kept), renders and animation videos. |
| `Tools` | `make_textures.py`, `make_ui.py`, `make_sounds.py`, `train_gesture_model.py`. |
| `Assets/Art`, `Assets/Audio`, `Assets/ML` | Exported FBX models, materials, UI sprites, sounds, the gesture model. |

Rebuilding the art (from the project folder):

```
blender -b --factory-startup --python Blender/scripts/phase2_toys.py
blender -b --factory-startup --python Blender/scripts/phase2_assembly.py
python Tools/make_sounds.py
```

Blender modifiers from the practicals are used throughout: Mirror (symmetric parts), Array (spokes, comb teeth, sails, sleepers along a curve, fences, chains), Bevel (soft toy edges) and Subdivision (rounded parts).
